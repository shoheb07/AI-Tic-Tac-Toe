# AI Tic Tac Toe

## Project Overview

AI Tic Tac Toe is a Python-based game where a player competes against an intelligent computer opponent. The AI uses the Minimax Algorithm to evaluate every possible move and choose the best action, making it extremely difficult to beat.

This project demonstrates fundamental Artificial Intelligence concepts, game development logic, and decision-making algorithms.

---

## Features

- Play against an AI opponent
- Unbeatable AI using Minimax Algorithm
- Console-based interface
- Winner and draw detection
- Lightweight and beginner-friendly

---

## Technologies Used

- Python
- Minimax Algorithm
- Game Logic
